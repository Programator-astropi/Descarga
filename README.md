# Focal — GitHub Pages

## Estructura

- `index.html` → página intermedia que verá la gente al escanear el QR.
- `mi-dia-2-6.html` → archivo que se descarga mediante el botón.

## Publicarlo en GitHub Pages

1. Crea un repositorio **público** en GitHub.
2. Sube `index.html` y `mi-dia-2-6.html` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la web.

La URL tendrá este formato:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

Esa URL es la que debe contener el QR.

## QR

Usa un **QR estático**, no un servicio de QR dinámico por suscripción. Mientras no cambies la URL de GitHub Pages, el mismo QR seguirá funcionando.
